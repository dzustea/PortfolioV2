Vyhlídkář web/app

Full-stack webová a mobilní aplikace zaměřená na objevování skrytých vyhlídek, laviček, car spotů a dalších jedinečných míst, která znají především místní. Uživatelé přidávají vlastní lokality, fotografie, hodnocení i komentáře. Projekt využívá interaktivní mapy, geolokaci, vlastní REST API, PostgreSQL s PostGIS, Cloudflare R2 pro fotografie a OpenAI API pro automatickou moderaci. Mobilní aplikace stojí na Capacitoru se sdíleným backendem.

  • Next.js
  • TypeScript
  • Tailwind CSS
  • Leaflet
  • PostGIS
  • Drizzle ORM
  • OpenAI API
  • Cloudflare R2
  • Capacitor

Kadeřnictví Hrabalová

Denisa Hair je moderní web a rezervační systém na míru pro kadeřnický salon. Zákazníkům nabízí přehledný online kalendář s výběrem volných časů a automatickým e-mailovým potvrzením. Součástí je administrace, ve které kadeřnice spravuje termíny, mění jejich stavy a ručně zapisuje telefonické objednávky. Systém garantuje, že se dva zákazníci nikdy nezarezervují na stejný čas.

  • PHP
  • MySQL / TiDB Cloud
  • JavaScript
  • CSS
  • REST API
  • Resend API
